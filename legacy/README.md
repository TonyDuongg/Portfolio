# Legacy source — preserved before the migration

These four files are an unchanged backup of the dirty working tree at the start
of the React/TypeScript migration, not just copies of the Git HEAD version.
They are kept for reference and are not included in the production build.

Their original relative media paths refer to the repository root (`avatar.png`,
`Download.mp3`, and `assets/`). To run the exact old version, copy these four files
into a separate folder together with those original media files.

The active site is now under `src/`. Do not edit legacy files to change the live UI.
